# `use-update-transaction`

Hook mutation update transaksi — masih pakai `useEntityForm` (bukan
`useDbMutation`+`BaseForm` seperti pola `features/accounts`), dan masih
berisi banyak komentar inline. BELUM dibersihkan/direfactor — ditunda
sampai form transaksi (`form.tsx` dan sekitarnya) selesai dirombak ke
pola baru, supaya tidak dikerjakan dua kali.
